Teraxmas will automatically locate your IP. If you are using a vpn, disable or use ?myip=put your public ipv4 (Your IP is not stored). Then download the Teraxmas Server(coming Soon) and run it. You can change the code in the server and run it on your own website and play it.
Compute hosting is not required, because you can get people outside of your network to access by letting them use ?myip=yourip.
example link: https://yogtogz.github.io/yogesh-games/teraxmas?myip=ip.v4
Remember to set the config host=network.
